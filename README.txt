POLAR ALIGN – bản web cho Safari (iPhone)
==========================================
Gồm 8 file: index.html, manifest.webmanifest, sw.js, icon-180.png, icon-192.png, icon-512.png, icon-512-maskable.png, README.txt

1) Đưa lên HTTPS (chọn 1 cách, miễn phí):
   - Netlify Drop: vào app.netlify.com/drop, kéo thả CẢ THƯ MỤC này. Nhận link https://xxx.netlify.app
   - GitHub Pages: tạo repository, tải các file lên, Settings > Pages > chọn nhánh main.
   (Mở file trực tiếp từ máy hoặc http:// thì Safari KHÔNG cấp cảm biến.)

2) Trên iPhone, mở link bằng Safari:
   - Bấm "Bắt đầu" > "Cho phép" quyền Chuyển động & hướng và Vị trí.
   - Mở Cài đặt trong trang, nhập độ lệch từ (NOAA Magnetic Field Calculator).
   - Bấm Chia sẻ > Thêm vào Màn hình chính để dùng như app (chạy được offline).

3) Nếu cảm biến không chạy: mở mục "Diagnostics (Safari)" cuối trang để xem
   HTTPS, quyền chuyển động, số sự kiện cảm biến, hướng la bàn. Nếu quyền bị từ chối:
   Cài đặt > Safari > Nâng cao > Dữ liệu trang web > xóa trang này, rồi mở lại.
